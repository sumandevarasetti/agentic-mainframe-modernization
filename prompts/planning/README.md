# Planning Prompts

Portable supplemental prompt patterns for the PLAN stage.

Use them after a human-approved DECIDE disposition and after native PP4Z implementation-planning capabilities where available.

Current pattern:

- `implementation-plan.md` — turns the approved disposition into bounded change slices, proof obligations, rollback criteria, and a human plan gate.

PLAN prompts may design and sequence work, but they must not modify source or begin TRANSFORM.
