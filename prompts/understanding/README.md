# Understanding Prompts

Portable supplemental prompt patterns for the UNDERSTAND stage.

Use them **after native product capabilities** when evidence gaps remain. They are not substitutes for PP4Z workflows or skills.

Current patterns:

- `capability-discovery.md` — capability-scoped application discovery;
- `known-unknowns.md` — application-local and evidence-boundary uncertainty accounting;
- `sme-questions.md` — targeted human validation questions.

The v0.3.4 Known Unknowns refinement was driven by AtlasPay Run 001: static analysis found many local source uncertainties but under-reported broader classes of unavailable production evidence.
