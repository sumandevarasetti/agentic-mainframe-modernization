# Supplemental Framework Prompts

Prompt assets in this repository standardize evidence requests and close gaps between native product outputs and Agentic Strangler evidence contracts.

## Native capability first

For IBM Bob Premium Package for Z, use verified native workflows, skills, commands and Z Understand analysis before substituting a generic prompt for the same function.

Examples:

- use native PP4Z `impact-analysis` for change/dependency impact;
- use PP4Z data-dictionary and documentation/explanation capabilities for semantic context and business-rule recovery;
- use the prompts here to request missing evidence, normalize the output format, identify known unknowns, or generate targeted SME questions.

These Markdown prompts are portable framework assets. They are not claimed to be IBM Bob-native Skill definitions.

Every prompt should declare or preserve stage, purpose, evidence expectations, permissions, uncertainty handling, human gate, and evaluation criteria.
