# AtlasPay Business Context

AtlasPay is a fictional global card authorization platform. The online authorization path validates accounts, evaluates merchant restrictions, determines the applicable transaction limit, and returns an authorization decision.

The modernization storyline in Project Bob focuses on a business request to make transaction limits more dynamic by incorporating product configuration, transaction context, jurisdiction, temporary customer controls, and current risk indicators.

This document is intentionally high-level. It does not enumerate every implementation dependency or exception path. Those are expected to be discovered from the estate.
