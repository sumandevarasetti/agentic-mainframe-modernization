# Contributing

Contributions should preserve the core rules:

- **No Evidence, No Progression**
- **Agents perform work. Humans retain authority**
- **Agent autonomy decreases as irreversibility increases**
- **Modernization is decision-first, not generation-first**
- **KEEP is a valid outcome**

## Requirements for executable artifacts

Every prompt/skill/agent/workflow should state:

1. framework stage
2. purpose
3. inputs
4. outputs
5. permissions
6. prohibited actions
7. human gate
8. evidence produced
9. evaluation criteria
10. portability/product-specific status

Do not contribute customer data, production credentials, proprietary bank code, internal-only vendor material, destructive defaults, or unverified product-specific syntax presented as fact.
