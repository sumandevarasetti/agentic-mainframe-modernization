# Publish This Starter Pack to GitHub

After creating an empty GitHub repository named `agentic-mainframe-modernization`:

```bash
git init
git add .
git commit -m "Initial Agentic Mainframe Modernization Framework v0.1.0"
git branch -M main
git remote add origin https://github.com/sumandevarasetti/agentic-mainframe-modernization.git
git push -u origin main
```

Before publishing, replace `REPLACE_WITH_OWNER` in `CITATION.cff` with the final GitHub owner.

Recommended first release/tag after review: `v0.1.0`.
